Portable, single-file executables — nothing to install. All builds and source: Releases · Source on GitHub

Folder A vs. Folder B

Recursively compares two folders by name and size, and flags every file that's missing, extra, or mismatched.

Duplicate finder

Scans any folder and groups files that are byte-for-byte identical (size + MD5 hash), not just same-named.

Side-by-side cleanup

Open any duplicate group and see every copy side by side — delete, rename, or move each one right from the app.

Sortable results

Click any column to sort by size, copy count, or name — large result sets load progressively without freezing.

HTML reports

Export a clean, shareable HTML report of every difference or duplicate group — no account or internet needed.

100% local & free

Open source and MIT-licensed. Nothing leaves your machine — no cloud upload, no telemetry, no cost.
